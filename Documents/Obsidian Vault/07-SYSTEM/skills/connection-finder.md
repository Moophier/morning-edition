# Skill: connection-finder (连接查找器)

## Purpose
每晚运行，发现你 vault 中不同笔记之间的隐藏关联，特别是A股投资方面的思考连接。

## Trigger
运行命令：`opencode run "执行技能: connection-finder"`

## Process

### 第一步：识别近期笔记
- 列出 `01-KNOWLEDGE\` 下最近48小时内创建或修改的所有笔记
- 重点：`stocks\`、`insights\`、`decisions\` 子目录

### 第二步：两两对比找连接

**什么是真正的连接：**
- 读两篇笔记合在一起，能产生单独读任何一篇都没有的洞察
- 不是两篇都在讲"科创板"
- 是"科创板估值逻辑"和"某公司产品净利率突出"放一起，得出这个标的可能被低估

**找什么类型的连接：**
- 同一行业不同标的的对比洞察
- 财务指标和股价表现的反常关系
- 筛选逻辑和具体标的的验证
- 研报结论和实际业绩的差距
- 两个独立信息源指向同一结论

### 第三步：评估连接质量
- 是否让你意外？（如果感觉早就知道，跳过）
- 是否有投资含义？（能影响决策吗？）
- 证据是否充分？

### 第四步：输出
每找到一个真实连接：
```
# 连接：[笔记A] ↔ [笔记B]

## 发现什么
[读两篇一起看到什么]

## 投资含义
[这个连接对投资决策意味着什么]

## 惊讶程度
[高/中 — 如果是显而易见的不报告]
```

保存到：`04-JARVIS-OUTPUTS\connections\[日期]-connections.md`
更新记忆库，标签：`connection`, `[日期]`
