# Skill: belief-tracker (信念追踪器)

## Purpose
每周一检查上周的所有内容，看是否有证据支持或挑战你在 CLAUDE.md 中记录的信念。

## Trigger
运行命令：`opencode run "执行技能: belief-tracker"`

## Process

### 第一步：读取当前信念
从 CLAUDE.md 的 "Current Beliefs and Working Theories" 部分提取所有信念

### 第二步：读取上周新增内容
- 列出 vault 中过去7天创建/修改的所有笔记
- 逐条评估与每个信念的相关性

### 第三步：评估相关性
对每条相关笔记：
- **CONFIRMS（支持）**：提供支持该信念的新证据
- **CHALLENGES（挑战）**：提供反对或使该信念复杂化的证据
- **IRRELEVANT（无关）**：跳过

### 第四步：只报告有意义的变化
- 无关紧要的挑战不报告
- 严重的挑战：评估是否需要修改信念还是仅需承认反面证据

### 第五步：生成报告
```
# 信念追踪 — [日期]

## 本周被支持的信念
信念：[陈述]
证据：[[笔记名称]] — [具体支持claims]

## 本周被挑战的信念
信念：[陈述]
证据：[[笔记名称]] — [具体挑战claims]
严重程度：[轻微/中等/重大]
建议行动：[更新/调查/承认]

## 建议的CLAUDE.md修改
[具体措辞修改，如果有足够的证据支持]
```

### 第六步：应用更新
如果证据充分且明显，直接更新 CLAUDE.md

保存到：`04-JARVIS-OUTPUTS\[日期]-belief-tracker.md`
