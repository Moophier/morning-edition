# Skill: weekly-synthesis (每周综合)

## Purpose
每周日生成一份深度周报，总结本周投资研究的所有收获，识别单日看不出的模式和趋势。

## Trigger
运行命令：`opencode run "执行技能: weekly-synthesis"`

## Process

### 第一步：收集本周材料
- 读取 `03-DAILY\` 下过去7天的所有每日笔记
- 读取 `01-KNOWLEDGE\stocks\` 下本周创建/修改的所有标的笔记
- 读取 `01-KNOWLEDGE\insights\` 下本周的思考
- 读取 `01-KNOWLEDGE\decisions\` 下本周的决策记录
- 读取 `01-KNOWLEDGE\notes\` 下本周所有笔记
- 读取过去7天的晨间简报
- 读取 CLAUDE.md 了解当前重点

### 第二步：诚实评估本周
- 计划做什么 vs 实际做了什么？
- 哪些标的取得了实质性进展？
- 哪些标的研究到一半停了？
- 决策质量如何？
- 本周主要在研究什么类型的标的？

### 第三步：识别周维度的洞察
- 有没有主题在多天反复出现？
- 有没有模式只在整周视角下才看得清？
- CLAUDE.md 中的哪个信念被本周证据支持或挑战了？
- 有没有连接发现改变了你对某标的的看法？

### 第四步：生成周报
```
# 每周综合 — [周日期范围]

## 本周一句话
[用一句话总结这周实际发生了什么]

## 有进展的标的
[具体、基于证据的进展描述]

## 无进展的标的
[诚实评估，原因而非借口]

## 本周决策回顾
[做了哪些决定，证据是否充分]

## 浮现的模式
[只有站在周维度才能看到的模式]

## 最重要的连接
[本周发现的最有价值的连接]

## 下周最重要的一件事
[基于本周证据，不是基于意愿]

## CLAUDE.md 更新建议
[具体需要修改的内容，如果有]
```

### 第五步：更新CLAUDE.md
如果证据充分，直接应用建议的更新

保存到：`04-JARVIS-OUTPUTS\syntheses\[日期]-weekly-synthesis.md`
