# Skill: morning-brief (晨间简报)

## Purpose
每天早上生成一份简报，发送到你邮箱。结合你的A股投资工作，重点关注：
- 昨晚有哪些重要市场信息
- 正在跟踪的标的的最新动态
- 今日需要做的投资决策

## Trigger
运行命令：`opencode run "执行技能: morning-brief"`

## Pre-Execution
1. 读取 `CLAUDE.md` 了解当前重点
2. 读取 `07-SYSTEM\memory\jarvis_memory.json` 获取近期背景
3. 确认输出目录可写

## Process

### 第一步：加载上下文
- 读取 CLAUDE.md，重点关注：当前关注标的、活跃问题、筛选规则
- 读取记忆库中最近7条晨间简报记录，避免重复
- 读取昨日的每日笔记（`03-DAILY\`目录下）

### 第二步：读取vault内容
- 扫描 `01-KNOWLEDGE\stocks\` 目录下最近修改的标的笔记
- 检查 `02-PROJECTS\` 下投资研究的当前状态
- 标记7天内没有更新的标的（可能需要关注）

### 第三步：外部情报
- 检查 `05-RESOURCES\market-intel\` 目录下昨晚的市场信息
- 如有财经新闻，记录与你关注的标的相关的要点

### 第四步：生成简报

输出格式：
```
# 晨间简报 — [日期]

## 今日最重要的一件事
[基于vault证据的 具体且可行动的描述]

## 市场概览
[昨晚到今早的市场相关信息，1-3条，无关则跳过]

## 标的跟踪状态
[每个正在关注的标的：一句话状态 + 今日关注点]

## 待决策事项
[列出所有悬而未决的投资决策，标注紧迫程度]

## 今日行动
1. [具体行动项]
2. [具体行动项]
```

### 第五步：质量检查
- 阅读时间不超过3分钟
- 每条都要有vault证据支撑
- 没有空话套话
- 最重要的那件事必须可以立即执行

### 第六步：发送邮件
- 使用 `07-SYSTEM\scripts\send_email.py` 发送简报
- 邮件主题：`晨间简报 [日期]`
- 发送到 .env 中配置的 EMAIL_TO 地址
- 同时保存到 `04-JARVIS-OUTPUTS/briefings/[日期]-morning-brief.md`（本地备份）

### 第七步：更新记忆库
在 `jarvis_memory.json` 中添加本次执行记录
