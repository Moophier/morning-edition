官方 FastAPI 教程（Web ID: 0 - fastapi.tiangolo.com）

FastAPI 官方网站（https://fastapi.tiangolo.com）提供了详细的入门教程，以下是重点内容：

1. 快速入门
    
    - 安装 FastAPI 和 Uvicorn：
        
        bash
        
        ```bash
        pip install fastapi uvicorn
        ```
        
    - 创建一个简单的 API：
        
        python
        
        ```python
        from fastapi import FastAPI
        
        app = FastAPI()
        
        @app.get("/")
        def read_root():
            return {"Hello": "World"}
        
        @app.get("/items/{item_id}")
        def read_item(item_id: int, q: str = None):
            return {"item_id": item_id, "q": q}
        ```
        
    - 运行应用：
        
        bash
        
        ```bash
        uvicorn main:app --reload
        ```
        
    - 访问 http://127.0.0.1:8000/docs 查看自动生成的 Swagger UI 文档。
        
2. 核心功能介绍
    
    - OpenAPI 集成：FastAPI 自动生成 OpenAPI 规范（Schema），支持 Swagger UI 和 ReDoc 文档。
        
    - 类型注解：利用 Python 类型注解（例如 item_id: int），自动进行参数验证。
        
    - 异步支持：支持 async 和 await，适合高并发场景。
        
3. 高级功能
    
    - 依赖注入：通过 Depends 实现代码复用，例如：
        
        python
        
        ```python
        from fastapi import Depends, FastAPI
        
        app = FastAPI()
        
        async def common_parameters(q: str = None):
            return {"q": q}
        
        @app.get("/items/")
        async def read_items(commons: dict = Depends(common_parameters)):
            return commons
        ```
        
    - Pydantic 模型：用于数据验证和序列化，例如：
        
        python
        
        ```python
        from pydantic import BaseModel
        
        class Item(BaseModel):
            name: str
            price: float
            is_offer: bool = None
        ```
        

DataCamp 的 FastAPI 教程（Web ID: 1 - [www.datacamp.com）](http://www.datacamp.com\)/)

DataCamp 提供了一篇详细的 FastAPI 入门教程（发布于 2022-09-26），以下是主要内容：

1. FastAPI 概述
    
    - FastAPI 是一个高性能的 Python Web 框架，基于 Starlette 和 Pydantic。
        
    - 特点：快速开发、高性能、易于使用、自动文档生成。
        
2. 与 Flask 的对比
    
    - Flask 是一个轻量级的微框架，适合小型项目，但缺乏 FastAPI 的高级功能（如自动验证和文档生成）。
        
    - FastAPI 更适合需要高性能和复杂功能的现代 API 项目。
        
3. 入门示例
    
    - 创建一个简单的 API，类似官方教程中的例子。
        
    - 强调 Pydantic 的作用：自动验证请求数据，避免手动检查。
        
4. 进阶内容
    
    - 错误处理：FastAPI 提供内置的错误处理机制，例如：
        
        python
        
        ```python
        from fastapi import HTTPException
        
        @app.get("/items/{item_id}")
        async def read_item(item_id: int):
            if item_id not in items:
                raise HTTPException(status_code=404, detail="Item not found")
            return {"item": items[item_id]}
        ```
        
    - 交互式文档：通过 /docs 或 /redoc 访问 API 文档，方便测试和调试。
        

Medium 文章：FastAPI 项目结构（Web ID: 2 - medium.com）

Medium 文章（发布于 2024-05-14）专注于如何组织 FastAPI 项目，提供以下建议：

1. 项目结构建议
    
    - 小型项目（单文件）：
        
        plaintext
        
        ```plaintext
        main.py
        ```
        
    - 中大型项目（模块化）：
        
        plaintext
        
        ```plaintext
        project/
        ├── main.py
        ├── api/
        │   ├── __init__.py
        │   ├── routes/
        │   │   ├── __init__.py
        │   │   ├── users.py
        │   │   └── items.py
        │   └── dependencies.py
        ├── models/
        │   ├── __init__.py
        │   └── item.py
        ├── tests/
        │   ├── __init__.py
        │   └── test_main.py
        └── config/
            ├── __init__.py
            └── settings.py
        ```
        
    - 说明：
        
        - routes/：存放 API 路由逻辑。
            
        - models/：存放 Pydantic 模型。
            
        - dependencies.py：存放共享依赖。
            
        - tests/：存放测试用例。
            
2. 结构化的好处
    
    - 可扩展性：模块化结构适合项目扩展。
        
    - 可维护性：代码组织清晰，便于维护。
        
    - 协作性：团队成员更容易理解和分工。
        
    - 可测试性：通过依赖注入和模块化，便于编写单元测试。
        
3. 依赖注入与测试
    
    - 使用依赖注入（Depends）解耦代码，方便测试。
        
    - 示例：使用 pytest 测试端点：
        
        python
        
        ```python
        from fastapi.testclient import TestClient
        
        client = TestClient(app)
        
        def test_read_root():
            response = client.get("/")
            assert response.status_code == 200
            assert response.json() == {"message": "Hello, World!"}
        ```

3. FastAPI 学习路径建议

基于上述教程内容，我为初学者和中级开发者整理了 FastAPI 的学习路径：

初学者（0-1 阶段）

1. 了解基础概念
    
    - 阅读 FastAPI 官方文档的 “First Steps” 部分（Web ID: 0）。
        
    - 学习 Python 类型注解和基础异步编程（async/await）。
        
2. 搭建第一个 API
    
    - 按照官方教程创建一个简单的 API，运行并访问 /docs 查看自动文档。
        
    - 理解路由（@app.get()）和响应（return）的工作原理。
        
3. 学习 Pydantic
    
    - 使用 Pydantic 模型定义数据结构，理解数据验证的作用。
        

中级开发者（1-2 阶段）

1. 掌握核心功能
    
    - 学习依赖注入（Depends），实现代码复用。
        
    - 使用 Pydantic 模型处理复杂数据（嵌套模型、默认值等）。
        
    - 利用 FastAPI 的错误处理机制（HTTPException）。
        
2. 项目结构优化
    
    - 参考 Medium 文章（Web ID: 2），将项目模块化。
        
    - 实现基本的测试（使用 pytest 和 TestClient）。
        
3. 探索异步特性
    
    - 编写异步端点（async def），结合数据库（如 SQLAlchemy）或外部 API。
        

进阶开发者（2-3 阶段）

1. 性能优化
    
    - 利用 FastAPI 的异步特性，优化高并发场景。
        
    - 使用 Gunicorn + Uvicorn 部署生产环境。
        
2. 扩展功能
    
    - 集成第三方库，例如数据库（SQLAlchemy、Tortoise-ORM）、认证（OAuth2、JWT）。
        
    - 自定义 OpenAPI 文档，添加额外的元数据。
        
3. 微服务架构
    
    - 将 FastAPI 用于微服务开发，结合消息队列（如 Redis、RabbitMQ）。
